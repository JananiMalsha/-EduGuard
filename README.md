# EduGuard

Smart School Student Safety, Attendance and Academic Performance Management System.

## Setup

1. Install XAMPP, clone this repo into `htdocs`.
2. Import `sql/eduguard.sql` using phpMyAdmin.
3. Copy `config/db.example.php` to `config/db.php` and edit if needed.
4. Open `http://localhost/EduGuard/`.

## Branches

- `main`: stable, tested releases only
- `develop`: integration branch
- `feature/*`: one branch per feature, merged into `develop` by pull request
